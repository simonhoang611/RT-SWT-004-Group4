# Bước 1.7 — Tinh chỉnh RQ (Research Question)

## 1. RQ và PICO Ban Đầu
* **RQ ban đầu:** Đối với user stories viết theo format Connextra, LLM tự động sinh Gherkin scenarios và step definitions so với BDD scenarios viết thủ công có đạt semantic similarity $\ge 0.85$ với expected behavior và executable không lỗi cú pháp không?
* **PICO ban đầu:**
  * **P:** User stories viết theo format Connextra.
  * **I:** LLM tự động sinh Gherkin scenarios và step definitions.
  * **C:** BDD scenarios viết thủ công.
  * **O:** Đạt semantic similarity $\ge 0.85$ và executable không lỗi cú pháp.

---

## 2. Những điểm tinh chỉnh và Nguồn (Từ Evidence Table)
*So sánh RQ ban đầu với bằng chứng từ evidence table để làm rõ các chi tiết còn mơ hồ:*

| Chỗ còn mơ hồ | Sau PRISMA xác nhận (Chi tiết tinh chỉnh) | Nguồn (Lý do) |
|---|---|---|
| "LLM" nào? | Cụ thể là **GPT-4o** | Bảng Evidence Table, cột Tool/LLM (chưa có paper nào dùng bản 4o chính thức) |
| Settings của LLM? | **Zero-shot, temperature = 0** | Thực tiễn tốt nhất về tính tái lập (Reproducibility best practices) |
| Nguồn User Stories? | Từ **$\ge$ 3 dự án SE** (Software Engineering) thực tế | Khắc phục hạn chế "Quy mô dữ liệu nhỏ/1 case study" lặp lại 5 lần trong Evidence Table |
| Ngưỡng 0.85? | Ngưỡng **0.85** dùng model `all-MiniLM-L6-v2` | Threshold set by course instructor (cột Kết quả không có paper nào dùng chuẩn này) |
| Ngưỡng Executable?| **$\ge 80\%$** | Threshold set by course instructor (dựa trên mức trung bình quan sát từ Evidence Table) |

---

## 3. PICO Tinh Chỉnh
* **P:** User stories theo format Connextra từ $\ge$ 3 dự án Software Engineering thực tế.
* **I:** Mô hình GPT-4o zero-shot (temperature=0) tự động sinh Gherkin scenarios và step definitions.
* **C:** Gherkin scenarios do expert software tester viết tay cho cùng user story.
* **O:** Metric 1: Đạt cosine semantic similarity (model `all-MiniLM-L6-v2`) $\ge 0.85$ • Metric 2: Executable syntax rate $\ge 80\%$.

---

## 4. RQ Cuối Cùng (Chính thức)
**"Does GPT-4o zero-shot (temperature=0) generate Gherkin acceptance test scenarios that achieve cosine semantic similarity $\ge 0.85$ (using all-MiniLM-L6-v2) with expert-written scenarios AND an executable syntax rate $\ge 80\%$ when applied to Connextra-format user stories from $\ge 3$ real-world SE projects?"**
