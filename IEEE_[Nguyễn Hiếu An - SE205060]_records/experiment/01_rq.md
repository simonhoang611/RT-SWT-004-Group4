## 4. RQ chính thức (đã tinh chỉnh)

> **"Does GPT-4o zero-shot (temperature=0) generate Gherkin acceptance test scenarios that achieve cosine semantic similarity ≥ 0.85 with expert-written scenarios AND executable syntax rate ≥ 80% when applied to Connextra-format user stories from SE projects?"**

**Bản tiếng Việt:**
> Liệu GPT-4o zero-shot (temperature=0) có sinh được Gherkin acceptance test scenarios đạt cosine semantic similarity ≥ 0.85 so với scenarios do expert viết tay, ĐỒNG THỜI đạt executable syntax rate ≥ 80%, khi áp dụng trên user stories format Connextra từ các dự án phần mềm?

## 5. PICO chính thức (đã tinh chỉnh)

| **O** | **Metric 1:** cosine similarity (all-MiniLM-L6-v2) **≥ 0.85**  ·  **Metric 2:** executable rate **≥ 80%** |
