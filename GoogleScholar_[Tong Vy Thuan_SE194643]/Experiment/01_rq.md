# Research Questions — SLR: LLM-Based Test Case Generation

---

## RQ chính thức

> **"Với tập user stories đa domain công khai (GBCV + 50 user stories thực tế, Python & Java), các open-source LLM thế hệ mới (LLaMA-3-8B-Instruct, Mistral-7B-Instruct, DeepSeek-Coder-7B) với few-shot prompting có đạt Gherkin syntax accuracy ≥ 90% và semantic similarity (BERTScore F1) ≥ 0.70 so với ngưỡng chuyên gia không?"**

---

## PICO

| Thành phần | Nội dung |
|---|---|
| **P (Population)** | Tập user stories đa domain công khai: GBCV (786 Python programs, Chang & Shirazi 2025) + 50 user stories thực tế (Karpurapu et al. 2024, Mendeley/blogs); tổng ≈ 836 user stories trải rộng nhiều domain |
| **I (Intervention)** | Open-source LLM thế hệ mới: LLaMA-3-8B-Instruct, Mistral-7B-Instruct, DeepSeek-Coder-7B; cấu hình few-shot prompting (3-shot), nhiệt độ = 0.0, sinh Gherkin scenarios từ user stories |
| **C (Comparison)** | Ngưỡng baseline: (1) Syntax accuracy ≥ 90% theo standard Gherkin-lint; (2) BERTScore F1 ≥ 0.70 so với reference scenarios do chuyên gia viết; (3) So sánh trực tiếp với GPT-3.5-Turbo (zero-shot, baseline từ Karpurapu 2024) |
| **O (Outcome)** | (1) Gherkin syntax accuracy (%); (2) Semantic similarity — BERTScore F1 (cosine similarity trên sentence embeddings); (3) Executable test rate (%); (4) Mutation kill rate (%) trên subset Java-convertible scenarios |

---

## Phân rã theo từng RQ

### RQ1 — Syntax Accuracy

> **"Các open-source LLM (LLaMA-3, Mistral, DeepSeek-Coder) với few-shot prompting có đạt Gherkin syntax accuracy ≥ 90% khi sinh test scenarios từ user stories không?"**

**Lý do ngưỡng 90%:** Karpurapu (2024) ghi nhận GPT-3.5/GPT-4 đạt ~100% với few-shot; threshold 90% là ngưỡng chấp nhận thực tiễn cho open-source models nhỏ hơn.

**Metric đo:** Gherkin-lint validation rate (% scenarios pass linter không có syntax error)

**Statistical test:** Binomial exact test (output nhị phân: pass/fail)

---

### RQ2 — Semantic Correctness

> **"Gherkin scenarios sinh bởi các LLM nói trên có đạt semantic similarity BERTScore F1 ≥ 0.70 so với reference scenarios do chuyên gia viết không?"**

**Lý do ngưỡng 0.70:** Tương đương mức "acceptable" trong các benchmarks NLG (BERTScore paper, Zhang et al. 2020); không có nghiên cứu nào trong SLR này đo BERTScore cho Gherkin — đây là ngưỡng exploratory.

**Metric đo:** BERTScore F1 (dùng `bert-score` library, model `microsoft/deberta-xlarge-mnli`)

**Statistical test:** Wilcoxon signed-rank test (output liên tục — BERTScore F1 per scenario)

---

### RQ3 — So sánh giữa các mô hình

> **"Mô hình nào trong ba open-source LLM đạt hiệu suất tổng hợp (syntax accuracy + BERTScore) cao nhất, và có sự khác biệt thống kê so với GPT-3.5-Turbo baseline không?"**

**Metric đo:** Combined rank score = (syntax_acc × 0.5) + (bertscore_f1 × 0.5); so sánh từng cặp model

**Statistical test:** Mann-Whitney U test (so sánh 2 hệ thống trên phân phối BERTScore F1)
