\subsection*{Data, Tool, and Ethics Disclosure}

This study involves no human participants; the empirical subjects are public software artifacts and model-generated Gherkin scenarios. Human-subjects review is therefore not applicable. GPT-5.4-mini is the system under evaluation and was also used to write the user stories from the reference files (Section~\ref{sec:method}). In the revision, an AI coding assistant (OpenAI Codex) drafted the 60 defect-audit labels, which an author reviewed, and AI assistants (OpenAI Codex and Anthropic Claude) helped write analysis scripts and draft text; Claude also prepared reading aids for the 15-file rater (rubric notes, an acceptance-criteria map, and reading sheets and a glossary for Fineract) that contained no labels; all numbers were recomputed from the released data and scripts, and the authors take responsibility for the content. The replication package contains the dataset, prompts, scripts, generated outputs, API logs, audit labels and revision analyses at \url{https://github.com/simonhoang611/RT-SWT-004-Group4}. The authors declare no external funding and no conflicts of interest.
